# Grim Dawn 独立物品生成器

面向《恐怖黎明》单人游戏的本地物品目录与生成界面。项目内置物品目录和中文名称映射；不会上传角色、存档或游戏数据。

> 仅限单人/离线环境使用。使用前请备份角色与共享仓库存档。

## 功能

- 搜索基础物品、前缀和后缀，并显示使用等级与品质。
- 紫色/传奇物品使用“生成无前后缀物品”；其独特属性属于物品记录本身。
- 绿色/稀有物品可在独立的“前缀”和“后缀”页面中选择词缀后生成。
- 可选择至多两项常用伤害或抗性，自动选择等级合法且数值最高的前后缀。
- 生成前拦截明显不合法的组合：传奇/史诗装备不能外挂随机词缀，词缀等级不能高于装备等级。
- 通过命名管道与注入到 `Grim Dawn.exe` 的本地 Helper 通信。

## 运行

1. 双击 `run_gui.cmd` 启动界面。
2. 若游戏已经启动，直接进入角色后点击“注入 Helper”。无需配置游戏目录。
3. 若游戏尚未启动，点击“选择游戏目录”，选择包含 `Grim Dawn.exe` 的安装目录；该路径仅保存为本机的 `data/settings.local.json`，不会提交到 Git。随后点击“启动游戏”。
4. 进入角色后点击“注入 Helper”，接受 Windows 管理员提示，再点击“检查连接”；状态应为 `ready`。
5. 选择物品并生成；请以背包中的实际结果为准。

## 目录

- `gd_gui.py`：Tkinter 图形界面。
- `catalog.py`：物品目录缓存逻辑。
- `data/catalog.json`：内置运行时物品目录，含等级、品质及中文显示名。
- `data/localization_zh/`：随项目发布的中文 Tag 映射，无需额外下载中文文本文件。
- `data/settings.local.json`：可选的本机游戏目录配置（自动忽略，不纳入 Git）。
- `native/`：x64 Helper 与注入器源码。
- `bin/`：当前可运行的 Helper 和注入器。
- `client/gd_client.py`：命名管道客户端。
- `tests/`：非侵入式 Python 测试。

## 验证

```powershell
python -B -X utf8 -m unittest discover -s .\tests -v
```

项目已移除约 917 MB 的解包游戏数据库；日常运行只依赖 `data/catalog.json` 和 `data/localization_zh/`。如需从头重建目录，应重新从游戏的 `.arz` 数据库导出记录。

## 限制

- “神话”是高等级的独立物品版本，不是可自由附加的随机前缀。
- 装备属性随机范围由游戏运行时决定；当前不承诺“满属性”生成。
- DLL 注入可能受管理员权限、游戏版本或 Windows 进程权限影响。
