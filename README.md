# Grim Dawn 独立物品生成器

《恐怖黎明》单人/离线模式的本地物品生成界面。项目内置物品目录、中文名称映射和材料目录；不会上传角色、存档或游戏数据。

> 仅限单人/离线环境使用。使用前请备份角色与共享仓库存档；以游戏背包或脚下的实际结果为准。

## 功能

- 搜索基础装备、前缀和后缀，并显示装备使用等级、品质与中文名称。
- 绿色/稀有装备可在独立的“前缀”“后缀”页选择词缀后生成；会拦截明显不合法的等级或品质组合。
- 蓝色、史诗、传奇与神话装备通过“生成无前后缀物品”生成；它们的固有属性来自装备记录本身。
- 为词缀显示对应效果，可选择至多两项伤害或抗性需求，辅助选择等级合法的高数值词缀。元素伤害按火焰、冰霜、雷电三系合并处理。
- 在“物品 → 材料”页生成固定值材料，并支持一次生成 `1`、`100` 或 `1000` 个。
  - 镶嵌物：108 项
  - 符文：51 项（中文名称含“铭文”或“符文”的条目独立归类）
  - 附魔：328 项
- 可选择游戏目录后启动游戏；若游戏已运行，则可直接进入角色后注入 Helper 并检查连接。
- 中文名称映射随项目发布，其他电脑无需再单独下载标签文本文件。

## 运行

1. 双击 `run_gui.cmd` 启动界面。
2. 已启动游戏时：进入角色后点击“注入 Helper”，接受 Windows 管理员提示，再点击“检查连接”。状态显示 `ready` 后即可生成。
3. 未启动游戏时：点击“选择游戏目录”，选择含有 `Grim Dawn.exe` 的安装目录；随后点击“启动游戏”。该路径只保存到本机 `data/settings.local.json`，不会提交到 Git。
4. 选择装备或材料并生成。材料的堆叠结果由游戏背包规则决定。

若界面显示“找不到命令管道”或 Helper 未连接，请确认角色已经进入游戏世界，并让修改器与游戏使用相同的管理员权限后重新注入。

## 目录

- `gd_gui.py`：Tkinter 图形界面。
- `catalog.py`：装备目录与本地化缓存逻辑。
- `data/catalog.json`：内置装备目录，含等级、品质和中文显示名。
- `data/materials.json`：内置材料目录，含镶嵌物、符文、附魔的中文名称和 DBR 路径。
- `data/localization_zh/`：随项目发布的中文 Tag 映射。
- `client/gd_client.py`：命名管道客户端。
- `native/`：x64 Helper 与注入器源码；`bin/`：当前可运行的二进制文件。
- `tools/build_material_index.py`：从完整解包数据库重建精简材料索引的维护工具。
- `tests/`：非侵入式 Python 测试。

## 数据与 Git

日常运行只依赖精简的 `data/catalog.json`、`data/materials.json` 和 `data/localization_zh/`。完整 `.arz` 解包记录仅用于维护索引，体积较大，已通过 `.gitignore` 排除，不应上传到仓库。

## 验证

```powershell
python -B -X utf8 -m unittest discover -s .\tests -v
```

## 限制

- “神话”是高等级的独立物品版本，不是可自由附加的随机前缀。
- 装备属性随机范围由游戏运行时决定；当前不承诺“满属性”生成。
- DLL 注入可能受管理员权限、游戏版本或 Windows 进程权限影响。
